# Descubra o Brasil – Portal Turístico

## Descrição

Portal turístico interativo desenvolvido para a agência fictícia **Brasil Encantado**, com o objetivo de divulgar destinos turísticos brasileiros, cultura e gastronomia. O site apresenta múltiplas páginas interligadas, recursos multimídia e estrutura semântica em HTML5 com CSS externo responsivo.

## Tecnologias Utilizadas

- HTML5 semântico
- CSS3 externo (Flexbox, Media Queries)
- YouTube iframes para vídeos incorporados

## Estrutura do Projeto

```
projeto-turismo/
├── index.html          → Página inicial
├── destinos.html       → Destinos turísticos
├── gastronomia.html    → Gastronomia brasileira
├── contato.html        → Formulário de contato
├── css/
│   └── style.css       → Estilos externos
├── img/
│   └── (imagens)
└── README.md
```
