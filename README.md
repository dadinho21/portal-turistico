# Descubra o Brasil – Portal Turístico

## Descrição

Portal turístico interativo desenvolvido para a agência fictícia **Brasil Encantado**, com o objetivo de divulgar destinos turísticos brasileiros, cultura e gastronomia. O site apresenta múltiplas páginas interligadas, recursos multimídia e estrutura semântica em HTML5 com CSS externo responsivo.
